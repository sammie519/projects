
ZombieFPSGame is a fast-paced first-person shooter built during our gaming class project. Players must survive waves of relentless zombies using a variety of weapons, quick reflexes, and strategic movement. The game emphasizes immersive environments, eerie sound design, and escalating difficulty to keep players on edge.

Features
- Survival Mode: Endless waves of zombies with increasing difficulty.  
- Weapon Arsenal: Pistols, shotguns, rifles.


Tech Stack
- Engine: Unity
- Language: C# or C++  
- Assets: Custom 3D models, textures, and sound effects  

Goal
This project is designed to help us learn core game development concepts such as FPS mechanics, AI behavior, level design, and player interaction—all while having fun creating a thrilling zombie survival experience.
